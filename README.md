# Easy App – English Learning Platform

Easy App is a cross-platform mobile application built with Flutter to help users learn English through simple lessons and interactive quizzes with progress tracking.

---

 Features
- User Authentication (Login – Signup – Profile)
- English lessons with clear and structured content
- Quiz after each lesson with automatic score calculation
- Tracking user progress and completed lessons
- Modern, clean, and responsive UI
- Local storage / backend integration for saving progress

---

 Technologies Used
- Flutter & Dart
- State Management (setState / Provider)
- Firebase / Local Storage
- Responsive UI Components

 Project Structure
 ```
lib/
├── screens/
├── widgets/
├── models/
├── services/
└── main.dart
```

1. Clone the project:
 ```
   git clone https://github.com/habibatarek28211/Eazy
 ```
2. Install packages:
    ```
   flutter pub get
     ```
3. Run:
  ```
flutter run
  ```
